# 六足战虫（Hexapod Havoc）

网页版波次生存 + 商店构筑的割草肉鸽。设计文档见 [DESIGN.md](DESIGN.md)。

技术栈：Phaser 3.90 + TypeScript + Vite。所有贴图都在运行时用代码绘制，不依赖外部素材。

## 运行

```bash
npm install
npm run dev        # 本机打开 http://localhost:5173
npm run dev:lan    # 同一局域网的手机也能访问（终端会打印局域网地址）
npm run build      # 类型检查 + 打包到 dist/
```

### 调难度用的模拟玩家（只在 `npm run dev` 时加载）

在浏览器控制台里：

```js
__bot.start('smart')   // smart 会躲怪和预警；circle 只会绕圈；idle 站着不动
__bot.start('smart', { character: 'rhino', difficulty: 4 })   // 指定角色和难度
__bot.start('smart', { character: 'stag', weapon: 'thunder-sword' }, { shop: false })   // 指定初始武器、不买东西，单独测一把武器
__bot.run(20)          // 往下打 20 波，返回每波的击杀、收入、最低血量
__bot.stop()           // 结束模拟，回到菜单
```

模拟期间存档处于沙盒模式，胜负和解锁不会写进浏览器里的真实存档。

## 操作

- 电脑：WASD / 方向键移动，P 或 Esc 暂停，Enter 确认
- 手机：横屏；在屏幕任意空白处按住拖动来移动
- 武器会自动瞄准最近的敌人攻击
- 主菜单右上角「设置」或暂停菜单里可以调音效音量、开关震屏

## 目录

```
src/
  art/                 代码绘制的全部贴图（甲虫和其他角色的身体、怪物、武器和道具图标、弹体、机关、草地…）
  config.ts            分辨率、地图大小、镜头、同屏上限等常量
  audio/               Web Audio 合成音效
  core/                属性与公式、经验与升级、商店规则、一局的状态 RunState、存档与设置、事件总线
  data/                数据表：武器、道具、怪物、波次（调数值改这里）
  entities/            角色外观（按角色配置腿的数量和位置，腿尖挂武器）、玩家
  systems/             刷怪、怪物与状态效果、命中结算、子弹、召唤物、机关、花蜜、武器、特效、空间网格
  scenes/              Boot → Menu → CharacterSelect → Game（+ UI 叠加）⇄ Intermission（升级/宝箱/商店）→ Result
  dev/                 开发用的模拟玩家（调难度）
  ui/                  按钮、浮动摇杆、属性面板等小部件
```
